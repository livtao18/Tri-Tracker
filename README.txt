TRI TRACKER: setup (about 10 minutes)

1. Host the folder (any one of these, all free):
   - Netlify: go to app.netlify.com/drop and drag this whole folder onto the page.
   - Cloudflare Pages: create a project and choose "Direct upload".
   - GitHub Pages: upload these files to a new repository, then turn on Pages in Settings.
   You get a web link. Use the random link the host gives you and don't share it.
2. On your phone, with internet, open the link once.
3. iPhone: open in Safari, tap Share, then Add to Home Screen.
   Android: in Chrome, open the menu and tap Install app.
4. Test: turn on airplane mode and open the app from your home screen.
5. Once a week, tap Export backup and save the file somewhere safe.
   Use Import backup to restore on a new phone.

Progress is saved only on the device you use. To update the app later, upload the new files to the same host.
